# Scrambler's Diner

Next.js website for Scrambler's Diner (Springfield, MO).

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm start` — run production server

## Routes

| Path | Page |
|------|------|
| `/` | Home |
| `/menu` | Menu |
| `/about` | About |
| `/gallery` | Gallery |
| `/contact` | Contact |
| `/sitemap` | Sitemap |
| `/privacy-policy` | Privacy Policy |
